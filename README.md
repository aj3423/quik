This fork of [QUIK SMS](https://github.com/quik-sms/quik/) is for demonstrating how to integrate [SpamBlocker](https://github.com/aj3423/SpamBlocker/) as an SMS screening provider.

See [the SMS screening protocol](https://github.com/aj3423/SpamBlocker/wiki/SMS-Screening-protocol) for details.
